# Economy Adapter Files

Add a new economy by creating exactly **one** YAML file here — no code changes
required (see [Z1-1.5] "Add a new economy in 1 file" guide, `docs/economy_schema.md`).

Reference examples: `sg.yaml` (Latin script path), `th.yaml` (Asian script path,
incl. Buddhist-era date handling).

Schema is defined and validated in `src/config/economy_config.py` [Z1-1.1, Z1-1.2].
