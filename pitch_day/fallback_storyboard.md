# Fallback Demonstration Storyboard

Target length: 60-90 seconds.

1. **Source** — show the archived official Singapore Statutes Online text for the PDPA.
2. **Evidence** — highlight the exact paragraph or section.
3. **Mapping** — show the corresponding RDTII indicator and rationale.
4. **Traceability** — show the source URL, article/location, and confidence.
5. **Output** — show the same record in CSV and JSON.
6. **Quality** — point out the NEW/KNOWN tag and the human-review note policy.

The video should use the completed Singapore P7 CSV/JSON and archived PDPA source. If no recording is available, follow this storyboard directly with those prepared files.
